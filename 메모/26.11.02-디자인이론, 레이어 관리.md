# 디자인 이론

1. 픽셀(pixel)
- 색상을 갖고 있는 가장 작은 단위
- 픽셀에 저장되어 있는 색상은 모두 다르다
- 계단현상 : 깨져 보이는 현상

2. 해상도
- ppi(pixel per inches) / dpi(dot per inches)
- 인치마다 가지고 있는 픽셀의 수
- 웹 기준 72ppi / 인쇄 기준 150ppi-300ppi

3. 색상모드(color mode)
- RGB : 디지털 컬러, 가산혼합
- CMYK : 인쇄용 컬러, 감산혼합

4. 비트맵(bitmap) / 벡터(vector)
- 비트맵 : 픽셀 기반 / 다양한 색상 표현 가능 / jpg, png, psd, bmp
- 벡터 : 점, 선 기반 / 다양한 색상 표현 불가능 / svg, .ai

[포토샵 설정]
- 공장 초기화 ctrl + alt +shift 누르면서 포토샵 열기
- general → auto show the home screen 체크 해제
- move tool - auto-select 체크 해제
- move tool - show transform controls 체크 해제 (transform 기능(Ctrl +T)의 활성화 비활성화 상태의 차이를 육안으로 확인하기 어려움)

[스마트 오브젝트]
- 고급 개체
- 이미지 픽셀 수 고정(이미지 사이즈를 조정해도 픽셀 값이 유동적으로 조정되거나 원래의 개수 유지)
- 단, 툴 사용 제한이 있음(브러쉬, 스탬프 등등)
- Rasterize layer 일반 레이어로 변경 / convert to smart object 고급 개체로 변경

[파일 저장]
- 다른 이름으로 저장 : Ctrl + Shift + s
- 덮어씌워 저장 : Ctrl + s
- 사본 저장 : Ctrl + alt + s

[복제]
- alt + 클릭 드래그 : 원하는 위치로 복사 가능
- ctrl + c/v : 원본 옆으로 복제 / 작업 하면의 정중앙으로 복제 → 어디로 복제되었는지 파악이 안되는 경우가 빈번하다
- ctrl + j : 원본 레이어 위로 복제

[레이어 생성]
- ctrl + shift + N : 레이어 생성, 사전 설정 가능
- crtl + shift + alt + N : 사전설정 없이 레이어 생성
