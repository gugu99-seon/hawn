### CSS에서 폰트 연결하는 방법
- 사용할 폰트(웹 폰트) 코드를 복사한 후 맨 윗줄에 붙여넣기
- body { 입력후 연결한 폰트 코드에서(font famliy) 복사+붙여넣기
- , 를 통해서 추가 연결가능

#### html 
- con->nav->ul(목록,제목)->li(리스트)
- ul과 li는 부모 자식관계로 무조건 같이 사용한다

##### css
- width : 너비, height : 높이
- border : 선
- margin : 여백
- html과 css 연결할 때는 class 제목이 틀리지 않게 한다.
