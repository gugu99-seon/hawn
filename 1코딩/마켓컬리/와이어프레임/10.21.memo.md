#### flex / item

- Flex는 요소를 배치하는 레이아웃 방식 → 전체 Item의 배치 방향과 정렬 제어
- Item은 Flex 레이아웃 안에 배치되는 자식 요소 → 개별 요소의 크기, 순서, 정렬 등을 제어
- flex-glow: 무슨 비율로 정렬할지 값 입력(flex-glow: 1; → 1:1 비율)
- flex-basis: 지정한 width 값을 기준으로 비율을 얼만큼 나눌지(0이면 비율 유지), Flex Item이 공간을 나눠 갖기 전에 기준이 되는 크기를 설정할 때 사용
