### 에이전트로 분석 요청하는 것
- 분석할 영역 개발자 모드(F12)-element 로 누르고 class복사 → 붙여넣기 후 이 영역의 높이, 여백, 폰트 크기, 굵기, 색상, 배경색, 선두께, 선 색상, 구성요소 간격 조사(분석)요청
- 복사한 클래스 붙여넣기 후 정식명칭 뭐라고해?
- 다운할 이미지 개발자 모드(F12)-element 로 누르고 class복사 → 에이전트에게 저장 요청("ooo폴더 안에 저장해줘")

### 컨포넌트(component)
- 반복적으로 사용하는 모듈
- 너비, display: flex;, 선, 여백 등
- 컨포넌트로 사용할 모듈을 CSS에서 만들고 html에서 클래스명 앞부분에 붙여넣기 후 띄어쓰기
01. html → <div class="con utility-con">
02. CSS→ .con / .utility-con 두가지 생성
- con에서 display: flex; 등 반복적인 부분을 넣고, .utility-con에는 안들어간다.

#### 이미지 html에서 넣는 방법
- img + tab 후 src= 이미지 적는 주소→ ./ 로폴더 선택, alt=이미지 이름 입력)
- 절대경로보다 상대경로를 사용하는 것이 좋다(절대경로는 경로가 조금이라도 바뀌면 찾기 어렵기 때문)

#### active(활성화) 만드는 방법
- html에서 .class이름 active 로 입력(예시 : <div class="brand-tab active">마켓컬리</div>)
- CSS에서 .class이름.active { 입력

#### css 속성
1. margin / padding
- margin : 바깥쪽 여백 / padding : 안쪽 여백
- 패딩 값을 넣을 땐 padding-top부터 입력
- Top/bottom/left/right 값 적용 가능

2. border
- 선
- border-radius : ; 로 둥글기 가능
- box-sizing: border-box 입력 시 선 박스 사이즈가 태그 사이즈, 선 크기 값을 포함하여 조정된다.

3. gap
- 요소 사이 간격
