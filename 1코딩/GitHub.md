# 오늘의 UI/UX · Frontend 학습 기록

- 학습 날짜 : 2026-10-14
- 학습 주제: 로컬 저장소와 원격 저장소의 차이
- 학습 키워드: #HTML #CSS #JavaScript

## 핵심 개념 정리

1. 로컬(Local)

- 정의 : 내 컴퓨터에서 파일을 저장하고 관리하는 공간
- 작동원리 : 내 컴퓨터에서 파일을 저장하고 관리하깅 위해서 사용한다.
- 작동 원리:

  ✅ 내 컴퓨터에 저장소를 만든다.

  ✅ 컴퓨터 내부에 파일을 저장하고 관리한다.

  ✅ 저장된 파일을 내 컴퓨터에서 확인하고 수정할 수 있다.

- 타인에게 공유 불가능
- 실제 사용 사례:

  ✅ 개인 컴퓨터에서 프로젝트 파일 관리

  ✅ 작업 중인 코드 및 파일 저장

  ✅ 컴퓨터 내부에서 파일 수정 및 관리

2. 원격(Repository)

- 정의 : GitHub에 저장되어 있는 저장소
- 사용하는 이유 : 인터넷을 통해 장소에 상관없이 파일을 보관하고 접근하기 위해 사용한다.
- 작동 원리:

  ✅ GitHub에 저장소를 만든다.

  ✅ 내 컴퓨터의 로컬 저장소와 원격 저장소를 연결한다.

  ✅ 파일을 원격 저장소에 저장하여 보관한다.

  ✅ 다른 장소에서도 GitHub에 로그인하여 파일에 접근할 수 있다.

- 타인에게 공유 가능
- 실제 사용 사례:

  ✅ 어디서든 로그인하여 동일한 프로젝트 파일 확인

  ✅ 컴퓨터에 있는 프로젝트 파일을 GitHub에 보관

  ✅ 메일로 파일을 따로 주고받지 않고 온라인에서 파일 관리

### 개념 도식화

| 구분      | 로컬(Local)          | 원격(Remote)              |
| --------- | -------------------- | ------------------------- |
| 저장 위치 | 내 컴퓨터            | GitHub                    |
| 파일 관리 | 컴퓨터 내부에서 관리 | 온라인에서 관리           |
| 접근 장소 | 해당 컴퓨터          | 인터넷 접속이 가능한 장소 |
| 주요 목적 | 파일 작성 및 수정    | 파일 보관 및 공유         |

#### 오늘의 핵심 요약

- 로컬(Local) = 내 컴퓨터에 있는 저장소
- 원격(Repository) = GitHub에 있는 저장소
- 원격 저장소를 이용하면 장소에 상관없이 로그인하여 파일을 확인하고 보관할 수 있다
- 원격은 타인에게 공유가 가능하지만 로컬은 불가능
